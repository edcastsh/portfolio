# Portfolio

Portafolio/CV personal construido con React + Vite + TypeScript.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
npm run format
npm run format:check
npm run typecheck
```

## Convenciones

- Flujo de desarrollo `backlog → story → pair` de [hola-ai](https://github.com/nschurmann/hola-ai).
- Validación de nombre de rama en `pre-push` mediante Husky.
- Release Please gestiona versiones al pushear a `main`.
- Ver `AGENTS.md` y `PROJECT_CONTEXT.md` para más detalles.
